# 单幅图像增强：基于 IAT 的高可行性改进方案（导师汇报可用）

## 1. 先说结论：做“亮度引导门控局部分支（IGL-Local）”

如果你已经复现了 IAT 基线，最稳妥、最容易出效果、工程改动可控的方案是：

- **不推翻原有 IAT 两分支结构**；
- 在现有 local 分支输出 `mul/add` 后，增加一个**亮度引导门控图** `g(x)`（1 通道）；
- 用 `g(x)` 对局部增强强度做像素级调节：暗区增强更强，亮区增强更弱；
- 全局分支（gamma + color matrix）基本保留，只做轻量联动。

一句话：**把“同一套局部增强参数作用全图”改成“按亮度自适应调节的局部增强参数”**。

---

## 2. 为什么这个方案靠谱

结合当前仓库的 IAT 代码，原始前向是：

1. local 分支预测 `mul` 和 `add`；
2. `img_high = img_low * mul + add`；
3. global 分支再做 gamma 和颜色矩阵校正。

这个流程很强，但也有常见问题：

- 暗区和亮区共享同一种局部增强强度，**容易出现局部过增强**；
- 暗区噪声会和信号一起被放大，**视觉上会“发灰、脏、颗粒感重”**；
- 不同场景亮度分布差异大时，局部增强稳定性下降。

而“亮度引导门控”直接针对上述问题：

- 在暗区令 `g` 更大，保留增强能力；
- 在亮区令 `g` 更小，抑制过增强和色偏；
- 额外参数量很小，训练稳定，**非常适合论文改进第一步**。

---

## 3. 模块设计（可直接放进论文方法图）

### 3.1 新增亮度估计与门控头

输入低照图 `I`，先计算亮度图（可微近似）：

`Y = 0.299R + 0.587G + 0.114B`

拼接后送入轻量卷积头：

`g = sigmoid(Conv3x3([I, Y]))`，输出维度 `B×1×H×W`。

### 3.2 门控增强公式

设 local 分支输出为 `mul`（>=0）和 `add`（[-1,1]），定义：

- `mul' = 1 + g * (mul - 1)`
- `add' = g * add`
- `I_mid = I * mul' + add'`

解释：

- 当 `g->1`：接近原 IAT 局部增强；
- 当 `g->0`：接近恒等映射，避免亮区被乱改；
- 所以增强强度会自动集中在该增强的位置。

### 3.3 与 global 分支联动（可选但推荐）

把 `I_mid`（而不是原始 `I`）送进 `global_net` 估计 gamma/color：

- `gamma, color = global_net(I_mid)`

这样全局校正是在“已做局部自适应修正”的中间结果上进行，更稳定。

## 4. 代码落地：你应当怎么改

下面按你当前仓库结构给出最短路径。

### 4.1 修改文件 1：`IAT_enhance/model/IAT_main.py`

#### A. 新增门控模块类（建议加在 `IAT` 类前）

- `class IlluminationGating(nn.Module):`
  - 输入 3 通道图像；
  - 计算亮度 `Y`；
  - `torch.cat([img, Y], dim=1)` -> 4 通道；
  - 两层卷积（4->16->1）+ `sigmoid`。

#### B. 在 `IAT.__init__` 中实例化

- `self.gate_net = IlluminationGating(in_ch=4, hidden=16)`

#### C. 在 `IAT.forward` 中替换局部增强

原来：

- `mul, add = self.local_net(img_low)`
- `img_high = img_low * mul + add`

改为：

- `mul, add = self.local_net(img_low)`
- `g = self.gate_net(img_low)`
- `mul_hat = 1 + g * (mul - 1)`
- `add_hat = g * add`
- `img_mid = img_low * mul_hat + add_hat`

然后：

- 若无 global：输出 `img_mid`；
- 若有 global：用 `img_mid` 进入 global 分支，得到最终输出。

> 注意：`g` 是 1 通道，`mul/add` 是 3 通道，PyTorch 会自动 broadcast。

### 4.2 修改文件 2：训练脚本（先改一个主脚本）

先在你当前主要复现脚本（如 `train_lol_v2.py`）加入两个轻量损失：

1. **亮度保序损失（L_rank）**：约束增强后亮度与 GT 亮度排序一致（可选 pair-wise 或简单 L1 亮度损失）；
2. **暗区平滑损失（L_dark_tv）**：仅在暗区对增强残差做 TV 约束。

总损失建议：

`L = L1 + 0.1*SSIM + 0.05*L_rank + 0.01*L_dark_tv`

权重先固定，不要一上来做大范围搜索。

## 5. 训练策略（能跑通、可复现）

### 阶段 1：冻结 global，先练 local+gate（20~30 epoch）

- 目标：让门控图先学会“哪里该增强”；
- 学习率可与 baseline 相同或略高（如 1e-4）。

### 阶段 2：全网络联合训练（再 80~120 epoch）

- 解冻 global 分支；
- 学习率降到 5e-5 或 1e-5；
- 保持数据增强与 baseline 一致，避免引入额外变量。

### 阶段 3：仅微调 global（10~20 epoch，可选）

- 固定 local+gate，轻调 gamma/color 以减少色偏。

---

## 6. 实验设计（导师最关心）

最少做 4 组消融：

1. Baseline (IAT)
2. IAT + Gate（仅门控）
3. IAT + Gate + 两个新损失
4. IAT + Gate + 新损失 + 两阶段训练

报告指标：

- 全参考：PSNR / SSIM / LPIPS
- 无参考：NIQE（可选）
- 效率：Params / FLOPs / FPS

可预期趋势（经验值，保守）：

- PSNR：+0.2 ~ +0.6 dB
- SSIM：+0.003 ~ +0.01
- LPIPS：下降（越低越好）
- 参数量：仅小幅增加

1. 提出亮度引导门控局部增强模块，实现像素级增强强度自适应；

3. 与 IAT 全局校正分支解耦兼容，几乎不增加计算量却稳定提升低照增强质量。

## 8. 常见坑位与规避

- **坑 1：门控塌缩到全 0 或全 1**  
  解决：给 `g` 加弱监督（例如与 `1-Y` 做 L1），权重 0.01 即可。

- **坑 2：颜色发黄或过冷**  
  解决：阶段 2 后半程降低 global 分支学习率到 local 的 0.5。

- **坑 3：训练初期不稳定**  
  解决：前 5 epoch 用 grad clip（如 0.5）并关闭过强数据增强。
